MilestonePay Desktop 0.2.0. FinTechathon 2026 demo: **test money only**.

**Install**
- macOS: open the .dmg, drag MilestonePay to Applications. The app is not signed by Apple: the first time, right-click → Open (or System Settings → Privacy & Security → Open Anyway).
- Windows: run the setup .exe (installs for your user only, no administrator rights). Windows SmartScreen may warn about an unknown publisher: More info → Run anyway.
- Linux: `sudo apt install ./milestonepay_*.deb`, then open MilestonePay from your apps.

Its screen opens in your browser. From this version on the app updates itself (Settings → App version and updates); every download is checked against the SHA-256 in latest.json.

**New**
- AI chat in the website's layout: saved chats (up to 20), tokens and tools per reply, token allowance and MCP calls on the side.
- MCP server page: turn it on or off, allow reading / asking the AI / requests for your signature, connect Claude Desktop or Cursor in one click, call log.
