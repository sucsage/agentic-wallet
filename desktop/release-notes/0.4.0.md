MilestonePay Desktop 0.4.0. FinTechathon 2026 demo: **test money only**.

**New: MilestonePay in its own window** (built with Electrobun). The same app, now in a native window with a tray icon and app menus instead of a browser tab. Links to documents, Stripe and GitHub open in your browser. Closing the window keeps the app running in the tray (for AI agents and syncing); Quit is in the tray menu.

- macOS: the windowed app is the main download (`…-window-macos-….dmg`).
- Windows and Linux: the windowed app is offered as a beta next to the classic version (which opens in your browser).
- Both versions share the same data on your computer; run one at a time.
- The windowed app does not replace itself yet: when a new version is out, install it from the release page (your data stays). The classic version still updates itself.
