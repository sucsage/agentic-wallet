MilestonePay Desktop 0.3.0. FinTechathon 2026 demo: **test money only**.

Update from the app: Settings → App version and updates, or download the installer for your computer.

**New**
- **MCP servers for the app's AI**: add one by a GitHub link, an npm package, a server URL, a JSON config ("mcpServers" format) or by pasting its code. It runs on your computer with the app's own runtime (no Node needed); the AI chat can use its tools, and the app asks you before each call (or "always allow" a server). They cannot sign or pay.
- **Everything the website does, in the app**: Waiting for you, Summary (AI explanation, CSV), Templates, Open calls, Policy & limits, Profile & privacy, send money, block / report / nicknames, group members, rule votes, invite link, leave, company registration, and on each deal "Details" (documents, files, guarantor, witness, decline or revised offer, split-payment parts, parcel tracking, website preview). Notifications bell, search, TH/EN.
- **AI chat**: replies stream as they are written, and the chats are the same as on the website.
- **No sign-in in the app**: create your account on the website, then link this computer with a code (Profile → Desktop app).
- The Claude Desktop / Cursor buttons are gone; this app still works as an MCP server for any client (JSON on the MCP page).
