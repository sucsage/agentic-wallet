MilestonePay Desktop 0.5.0. FinTechathon 2026 demo: **test money only**.

**The app in its own window is now the only version.** The classic build that opened in a browser tab is no longer built. If you still use it, download 0.5.0 from the website's Download page, quit the old app (Settings → Quit) and install the new one: your wallet data stays.

- **Black title bar.** On macOS and Windows the window has a black bar across the top, with no native title bar (macOS keeps its close/minimize/zoom buttons on it; Windows gets its own minimize, maximize and close buttons). Drag the bar to move the window; double-click it to maximize.
- **Fewer menus.** The Edit and Window menus are gone. Copy, paste and undo still work (they are in the app menu).
- **Fits your screen.** The first window is sized to your screen and centered, and the app remembers its size and position. Display size: Settings → Display size, or Ctrl/⌘ + and −, Ctrl/⌘ 0 to fit the screen again.
- **Web search in the AI chat.** The AI can search the web and read pages, on your computer (no key). Turn it on or off with the new Tools button next to the message box.
- **Tools button in the AI chat.** See the AI's tools, turn MCP servers on and off, and add recommended ones.
- **Find MCP servers.** The MCP page lists recommended servers (DeepWiki, Context7, Microsoft Learn, Memory, Sequential thinking, Files) and searches the official MCP Registry; one click adds a server. Servers that need a key are added turned off until you fill it in.
- Updates: when a new version is out, Settings → App version shows a Download button for your computer.
