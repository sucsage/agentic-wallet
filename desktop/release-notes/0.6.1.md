Kravii 0.6.1. FinTechathon 2026 demo: **test money only**.

**Fixes buttons that sometimes hung** (Sign, Deliver, Approve, Confirm, Save…):
- Every call to the website now has a time limit. Before, one request that never answered (a slow network or server moment) held every move after it, because moves run one at a time.
- The background sync (every 20 seconds) now waits its turn: it runs only when nothing else is running or waiting, and it no longer piles up when the server is slow.
- The screen gives up after a few minutes at most with a message, so a button never spins forever.
- MCP servers start in parallel and get a few seconds: one that is slow or broken no longer holds the AI chat or the MCP page ("starting…" shows instead), and a failed server is tried again after a minute.
