MilestonePay Desktop 0.5.1. FinTechathon 2026 demo: **test money only**.

**Windows**
- **One Setup.exe** with a proper install wizard (no zip, no terminal window): installs for you only (no administrator rights), adds MilestonePay to the Start menu (and the desktop if you want) and to Apps → Uninstall.
- **No terminal window** next to the app any more.
- **The window's title bar is back** (dark; black on Windows 11), with no menu bar in the window.
- **The MilestonePay icon and name** on the taskbar, in Alt+Tab and in Task Manager (it showed Bun's).
- **Sharp on any display scaling** (125%, 150%…): the app now tells Windows it handles scaling itself, so text is no longer stretched and blurry.
- If you installed 0.5.0 from the zip, quit it (tray → Quit) and install 0.5.1; you can then delete the old folder. Your wallet data stays.

**All computers**
- Right-click on the app's screens no longer shows the browser's menu (Back, Reload, Inspect). Text boxes and selected text still have Cut / Copy / Paste.
- "Fit this screen" display size stays at 100% on usual screens (sharper text); change it in Settings → Display size.
