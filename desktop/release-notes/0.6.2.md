Kravii 0.6.2. FinTechathon 2026 demo: **test money only**.

**Updates from inside the app.** When a new version is out, Settings → App version shows "Update to … now": Kravii downloads it, checks it against the release's SHA-256, closes and opens again as the new version. Your wallet data stays; you unlock with your passphrase again.

- macOS: works when Kravii is in a folder you can write to (Applications is fine). Running from the disk image: drag it to Applications first.
- Windows: the installer runs silently over the installed app and opens Kravii again.
- Linux: the Download button as before.

This version is the first one that can update itself: from 0.6.2 on, later versions install from inside the app.
