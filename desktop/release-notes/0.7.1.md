Kravii 0.7.1. FinTechathon 2026 demo: **test money only**.

- **Windows: the window fills the screen.** It opens maximized the first time, and again if it was closed maximized; a window left at an odd size by an older version opens maximized once.
- **Settings → Privacy and developer tools**
  - *Allow screen recording and screenshots of Kravii* (on by default). Turn it off and screenshots, screen recordings and screen sharing show the Kravii window blank: on Windows the window is left out of captures, on macOS it is not shared.
  - *Developer tools (Inspect, F12)* (off by default). While off, F12, Ctrl+Shift+I / ⌘⌥I and the right-click menu (which offers Inspect) do nothing.
- Settled milestones no longer show a due-date countdown.
- From 0.7.0 on, this update installs without an installer.
