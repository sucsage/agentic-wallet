Kravii 0.7.6. FinTechathon 2026 demo: **test money only**.

- Windows: sending a message to the AI chat no longer flashes a black command window. MCP servers from npm are now installed once in Kravii's data folder and started directly with the app's own Bun (before, `bun x` started them as a second process, which opened a console window). A server that stops by itself is tried again after 10 minutes or when you restart it on the MCP page, not on every message.
- Private links for a group's or company's deals now show the group's name ("Chinesegreycompany wants to hire you"), not the name of the member who sent the link.
