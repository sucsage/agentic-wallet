Kravii 0.7.2. FinTechathon 2026 demo: **test money only**.

- **AI chat fits the window.** On a wide window the page no longer scrolls. Only the conversation scrolls with the mouse wheel, and the chat list and side panel scroll on their own if they are long.
- **Every page uses the full width.** Pages used to stop at 1180 px and leave empty space on the right of a large screen.
- **Installing MCP servers from a link.** Ask the AI "install this MCP server: https://github.com/owner/repo", or paste the GitHub link on the MCP page.
  - The app takes the npm package the repository publishes and runs it with its own Bun. You are asked before it is added.
  - An npm package name or a remote https MCP URL works too.
  - Servers that need a key or a login (for example Google Docs) are added, then show what is missing on the MCP page. Fill it in under Edit config.
