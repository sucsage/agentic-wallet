Kravii 0.7.3. FinTechathon 2026 demo: **test money only**.

**Windows: in-app updates now work.**

On 0.7.1 and 0.7.2, "Update now" closed Kravii, flashed a console window, and did not reopen; Kravii stayed on the old version. The cause: the helper that swaps the files was started from inside the app's `bin` folder, so Windows would not let that folder be replaced, and the helper stopped before it opened Kravii again.

Now the helper:
- runs from outside the app folder;
- retries while Windows still holds files;
- always opens Kravii again;
- runs without a console window;
- writes what happened to `update-log.txt` in the data folder. If an update does not go in, Settings says why.

**If you are on 0.7.1 or 0.7.2 on Windows:** install this version once with `Kravii-0.7.3-window-windows-x64-Setup.exe` from the download page. Your wallet data stays. Updates from inside the app work from 0.7.3 on.
