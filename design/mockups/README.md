# Mockup หน้าเว็บ

Mockup ทุกหน้าของระบบแลกไฟล์งานกับคริปโต ดูแบบกดลิงก์ไปหากันได้ที่
[Agentic Wallet Mockups](https://claude.ai/artifact/UXgi1jvCXMvTsoPfpt8qcD)
(ต้องได้รับแชร์จากเจ้าของลิงก์ก่อน)

ไฟล์ `.dc.html` ต้องเปิดผ่านลิงก์ด้านบน ถ้าเปิดตรงในเบราว์เซอร์จะแสดงผลไม่ครบ
`canvas.json` เก็บตำแหน่งของแต่ละหน้าบนแคนวาส

| กลุ่ม | ไฟล์ | หน้า |
|---|---|---|
| เริ่มต้นใช้งาน | `Main.dc.html` | หน้าแรก |
| | `Login.dc.html` | เข้าสู่ระบบ |
| สร้างและตอบรับดีล | `Dashboard.dc.html` | ดีลของฉัน |
| | `NewOffer.dc.html` | สร้างข้อเสนอด้วย AI |
| | `OfferReview.dc.html` | ตรวจและตอบรับข้อเสนอ |
| ห้องดีล | `DeliverWork.dc.html` | ผู้ขายส่งงาน |
| | `ReviewWork.dc.html` | ผู้ซื้อตรวจงาน |
| | `ReceiveFile.dc.html` | รับไฟล์ |
| | `Dispute.dc.html` | ข้อพิพาท (มุมมองคนกลาง) |
| บัญชี | `Wallet.dc.html` | กระเป๋าและ AI agent |
| | `Profile.dc.html` | โปรไฟล์และการตั้งค่า |

ชื่อคน ยอดเงิน และ address ในทุกหน้าเป็นข้อมูลตัวอย่าง
